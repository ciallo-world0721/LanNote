# LanNote 探索版

主线的双栏笔记 + 单条笔记共享编辑。点「共享」时打开的那条笔记才是共享笔记，
点「关闭共享」或者关掉发起者的程序，会话就结束，正文各留各的。

目录里的东西只给 `explore/` 用，`app/` 一行没改。

## 跑

```bash
../integration/.venv/Scripts/python.exe main.py
```

打包版直接双击 `LanNote探索版.exe`，数据在它同级的 `data/lannote.db`。

同机开两个实例（单实例锁固定用 `lannote-live.lock`，带 `--db` 时跳过锁，给测试用）：

```bash
python main.py --name A --db "$TEMP/a.db"
python main.py --name B --db "$TEMP/b.db"
```

`--share` 打开就进入共享面板第二步，省一次点击，用来看别人能不能加进来。

## 用

1. 打开一条笔记，点右上「共享」。
2. 面板第一步显示当前网络（WiFi 名 + 本机 IP），「确认共享」后开始广播。
3. 对面也点「共享」，会自己当受邀者加入，并且自动打开你这条笔记。
4. 面板「收起」和右上角 X 都只是隐藏面板，共享还在，顶栏显示「共享中」，头像右下角有个绿点。
5. 发起者「关闭共享」结束整个会话；受邀者看到的是「退出共享」，只退出自己。
6. 发起者退出程序或掉线，其他人结束会话并保留最新正文。

左栏标题右边的圆圈是此刻在这条笔记里的其他人（最多 3 个，多的显示 +N），
自己永远不画。正文里对方的圆圈画在它的光标处。切换笔记、对方离开都会立刻消失。

左上角头像圈 + 名字，点一下改名（最多 5 个字），名字和颜色存在 `settings` 表。

## 自测

```bash
../integration/.venv/Scripts/python.exe selftest.py   # 迁移/插入替换/badge/收起不算停
../integration/.venv/Scripts/python.exe nettest.py    # 起两个进程真网络跑一遍
```

`nettest.py` 会自己开两个进程（offscreen），A 开共享、B 加入、两边打字、
A 关共享，最后比对两边的正文和落库结果。

## 打包

```bash
../integration/.venv/Scripts/python.exe build_exe.py
```

或者按 SPEC 第八节直接调 PyInstaller。产物在本目录，`build/` 里是中间文件和 ico。

## 已知限制

- **同时点共享**：`started` 早的当发起者，同一毫秒就比 iid（小的当）。后到的那个
  从 host 降成受邀者，发 `NEED` 拿对方的笔记，本地正文被对方快照替换。
  `started` 是各自的系统时钟，两台机器时间差大的时候判断会偏。
- 只同步正文。标题、颜色只在加入时随 `NOTE` 带一次，之后谁改都不广播。
- 同一 uid 的笔记加入时用发起者快照盖掉本地正文，不做合并；会话内也没有离线补发。
- 不做加密、房间口令、跨网段，也没有中继；UDP 广播到不了的网络发现不了对方。
- 发起者掉线不重选 host：受邀者等 4 秒，没重连就按「会话结束」处理。
- 同网段所有人共用一个固定发现池，没有房间名。两组人同时用会并成一个会话，
  后加入的一方会被换成最早发起者的笔记；这是当前设计的边界，不是 bug。
- 共享结束后控件撤销栈会清空，Ctrl+Z 撤不回共享前的历史。
- 共享的是点按钮时打开的那条笔记；换笔记只是把光标标记挪走，不同步别的笔记。
- 正文以纯文本为准，loro 快照只在会话内存里活着，不落库。
- 共享中把共享笔记清空不会删行（避免会话悬空），共享结束后仍按主线规则处理空笔记。
