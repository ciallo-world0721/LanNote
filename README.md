# LanNote

局域网里能一起写的便签。

一张便签可以被几个人同时打开，各写各的一段，各自点确认，互不覆盖。

> 现在还很早。仓库里只有想法和一份需求文档，代码一行都没有。
> 如果你是从未来翻到这里的，往下看 `docs/requirements.md` 会知道当时在想什么。

## 这个项目解决什么

宿舍或实验室里有同一个 WiFi，几个人想一起记点东西——不注册账号、不连外网、不建工作区。
