# LanNote

我想做一个满足我自己需求的便签软件。当然，市面上现在已经有很多便签软件了，我这个也只能算是一个练手作品。

但不得不提的是，我确实有一些自己的小需求。之所以叫这个名字，是因为我想让它实现局域网内的互联。市面上可以进行共享编辑的，一般都是通过云端。但是云端又不可能及时进行修改。有些手机厂商，比如说 vivo 做的办公套件，它是可以实现手机端修改的同时，电脑端会有提示，刷新之后也可以显示出来。但这也不是真正意义上的实时。

于是要怎么做呢？我的想法是，局域网比较可行，所以我们就先这样吧。

说得有点凌乱，但反正这只是一个个人项目，应该也不会有别人看。如果之后要更新的话，我可能会把这一段话也改一下。

总之先做比较好做的 Windows 端吧。打算用 Python + PySide6 做界面，WebSocket 做局域网通信，SQLite 存数据。姑且先这样。因为我对这些比较熟，网上的例子也比较多，我打算也进行一些开源项目的二次开发，避免反复造轮子。但之后可能会换用一些更现代的架构，不过我们先这样。

就当在这里立个 flag。
